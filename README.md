# Portfólio — Thiago Santos

Site pessoal onde apresento minha trajetória como desenvolvedor backend Java: experiência, projetos, stack e contato.

**Acesse:** https://thiago-santos.vercel.app

## Seções

- Início
- O que eu faço
- Experiência
- Projetos
- Sobre
- Stack
- Contato

## Tecnologias

- HTML, CSS e JavaScript puro, tudo em um único `index.html`
- Google Fonts (Bricolage Grotesque e Geist Mono)
- Layout responsivo para desktop e celular
- Deploy contínuo na Vercel a partir da branch `main`

## Como rodar

Basta abrir o `index.html` no navegador.
