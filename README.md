# Portfólio Thiago Henrique Santos

Um portfólio moderno e responsivo desenvolvido para destacar os projetos e habilidades de Thiago Henrique Santos.

## 🚀 Características

- **Design Moderno**: Interface limpa e profissional com gradientes e animações suaves
- **Totalmente Responsivo**: Adaptável a todos os dispositivos (desktop, tablet, mobile)
- **Animações Interativas**: Efeitos de scroll, hover e transições fluidas
- **Integração com GitHub**: Conecta automaticamente com a API do GitHub para mostrar projetos
- **Formulário de Contato**: Sistema de contato integrado com validação
- **Performance Otimizada**: Carregamento rápido e otimizado para SEO

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível
- **CSS3**: Estilos modernos com Flexbox e Grid
- **JavaScript (ES6+)**: Interatividade e animações
- **Font Awesome**: Ícones profissionais
- **Google Fonts**: Tipografia Inter para melhor legibilidade

1. **Abra o arquivo index.html** no navegador

2. **Personalize**:
   - Edite as informações pessoais no HTML
   - Modifique as cores no CSS
   - Adicione novos projetos na seção de projetos

## 📝 Personalização

### Alterando Informações Pessoais
Edite o arquivo `index.html` nas seguintes seções:
- Hero section (nome, título, descrição)
- Seção sobre (biografia)
- Informações de contato

### Modificando Cores
No arquivo `styles.css`, altere as variáveis CSS:
```css
:root {
  --primary-color: #2563eb;
  --secondary-color: #fbbf24;
  --text-color: #333;
}
```

### Adicionando Novos Projetos
Na seção de projetos do HTML, adicione novos cards:
```html
<div class="project-card">
  <div class="project-image">
    <i class="fas fa-icon-name"></i>
  </div>
  <div class="project-content">
    <h3>Nome do Projeto</h3>
    <p>Descrição do projeto</p>
    <div class="project-tech">
      <span class="tech-tag">Tecnologia</span>
    </div>
    <div class="project-links">
      <a href="link-do-projeto" class="project-link">
        <i class="fab fa-github"></i> Ver Código
      </a>
    </div>
  </div>
</div>
```

## 🌐 Deploy

### GitHub Pages
1. Faça push do código para o GitHub
2. Vá em Settings > Pages
3. Selecione a branch main
4. Acesse o link gerado

### Netlify
1. Conecte o repositório GitHub
2. Configure o build command (não necessário para HTML estático)
3. Deploy automático

### Vercel
1. Conecte o repositório
2. Deploy automático
